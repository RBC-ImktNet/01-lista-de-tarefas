## Demonstração online

**[Abrir Taskflow](https://rbc-imktnet.github.io/taskflow/)**

Aplicação de produtividade criada com React e TypeScript. O projeto permite organizar tarefas, acompanhar o progresso e manter os dados salvos no próprio navegador.

## Funcionalidades

- Criar, editar, concluir e excluir tarefas
- Definir prioridade e prazo
- Buscar e filtrar tarefas por status
- Indicador de progresso em tempo real
- Persistência automática com `localStorage`
- Interface responsiva para celular e desktop
- Estados vazios e validação do formulário

## Tecnologias

- React
- TypeScript
- Vite
- Lucide React
- CSS responsivo

## Como executar

```bash
npm install
npm run dev
```

Acesse o endereço exibido no terminal, normalmente `http://localhost:5173`.

## Build de produção

```bash
npm run build
npm run preview
```
